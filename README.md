# Mini-Lab-Back

Mini-Lab: Sistema de Gestión de Laboratorio de Análisis Clínicos

## Tecnologías

- Node.js
- TypeScript
- Express
- PostgreSQL

## Requisitos

- Node.js
- npm

## Instalación

```bash
npm install
```

Crea un archivo `.env` a partir de `.env.example` y configura sus valores (ponerle 3000)

## Desarrollo

```bash
npm run dev
```

## Comprobaciones

```bash
npm run typecheck
npm run lint
npm run format:check
npm run build
```
